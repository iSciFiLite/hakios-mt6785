# HakiOS MT6785 — SALAA та Nemo

[English documentation](README.md) є основною й актуальною.

Цей репозиторій містить експериментальні профілі для Realme 7 SALAA (RMX2151) і Realme 6 Nemo
(RMX2001) на MediaTek MT6785. Порт неповний: профілі ще не мають перевіреного завантажувача,
handoff для UFS чи робочих драйверів дисплея та периферії. Тут немає завантажуваного образу.
Не прошивайте цей код на телефон.

Документація про стан, залежності, ліцензії та план портування: [README.md](README.md).
